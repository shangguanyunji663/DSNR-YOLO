## 你将学到什么

读完这套文档并跑通本项目，你应该能独立回答：

1. 目标检测和图像分类有什么区别？mAP50、mAP50-95 到底怎么算？
2. 一个 3×3 卷积的参数量/FLOPs 怎么手算？深度可分离卷积为什么能省 8~9 倍？
3. 论文的四大改进（DSNRblock / GhostConv / BiFPN / 混合损失）分别解决什么问题？
4. 如何把自己写的模块"插"进 ultralytics 框架（yaml + 注册补丁）？
5. 如何在真实数据集（DIOR/SIMD）上训练、评估、读懂论文里的每一张表？

## 六个阶段（建议按顺序走）

| 阶段 | 内容 | 对应文档/代码 | 预计时间 | 过关标准 |
|---|---|---|---|---|
| ① 概念入门 | 目标检测是什么、YOLO 思想、指标 | docs/01 | 2~3 h | 能给别人讲清 mAP 怎么算 |
| ② 轻量化基础 | 卷积参数量、深度可分离卷积、注意力、FPN 家族 | docs/02 | 3~4 h | 能手算 DSNRblock 省了多少参数 |
| ③ 论文精读 | 背景动机、整体架构、图1逐层 | docs/03 | 2 h | 能画论文图1的简化版 |
| ④ 模块精讲 | DSNRblock / GhostConv+BiFPN / 混合损失 | docs/04~06 + `dsnr_yolo/` 全部代码 | 6~8 h | `python tests/test_modules.py` 全过且明白每条断言 |
| ⑤ 实验解读 | 数据集、尺度划分、消融表、对比表 | docs/07 | 2 h | 能复述表2每一行的含义 |
| ⑥ 动手复现 | 代码结构、环境、数据、训练 | docs/08~09 + `scripts/` | 4~6 h | 玩具集冒烟通过 + (可选)DIOR 正式训练 |

> 零基础建议总投入 20~25 小时。已有深度学习基础的可从阶段③直接开始。

## 每阶段的"动手环节"

学习这套材料**必须动手**，每个阶段都有对应的验证动作：

```bash
# ①② 之后：跑模块单元测试（8 个测试对应论文全部公式）
python tests/test_modules.py

# ③④ 之后：跑整网自检（构建/参数量/前向/损失反传四步）
python scripts/verify_model.py

# ⑤⑥ 之后：跑玩具数据集冒烟训练（1 分钟，GPU 或 CPU）
python scripts/make_toy_dataset.py
python scripts/train.py --data data/toy.yaml --epochs 3 --imgsz 320 --batch 4 --nbs 4 --device 0
```

## 学完之后（延伸方向）

论文 4.2 节自己给出了三个未来方向，也是很好的练手题：
1. 优化 BiFPN 融合策略 + 动态锚框分配（密集场景）；
2. 自适应去噪模块 + DSNRblock 融合（雨雪雾鲁棒性）；
3. 多模态融合检测（可见光/红外/SAR）。

对应练习：先在 `custom_parse.py` 的注册表里加一个你自己的模块，再在 yaml 里用起来——
走通一遍，你就掌握了"魔改 YOLO"的完整方法论。
