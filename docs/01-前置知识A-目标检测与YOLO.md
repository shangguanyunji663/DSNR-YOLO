# 01 · 前置知识 A —— 目标检测与 YOLO

> 目标读者：零基础。读完你应能理解"检测模型在算什么、指标在量什么、YOLO 强在哪"。
> 配套动手：无需代码，但请把文中两个小例子手算一遍。

## 1. 目标检测 = 分类 + 定位

图像分类只回答"这张图里是什么"；**目标检测**要同时回答：

1. **有什么**——每个目标的类别（飞机？储罐？）；
2. **在哪里**——用一个矩形框（bounding box）框住它。

一个检测框的标准写法有两种（本项目两种都出现，务必分清）：

```
xyxy : (x1, y1, x2, y2)   左上角 + 右下角            ← 损失计算内部使用
xywh : (cx, cy, w, h)     中心点 + 宽高              ← YOLO 标签文件使用（归一化到 0~1）
```

例：一张 640×640 的图里有一个 100×80 的框，中心在 (200, 300)：
YOLO 标签写成 `0 0.3125 0.4688 0.1562 0.1250`（类别号 + 4 个归一化数）。

### 遥感目标检测的特殊难点（论文引言）

| 难点 | 说明 | 论文对应的应对 |
|---|---|---|
| 目标小且密 | 一张图里几百个车辆/船只，占图面积 <0.1% | NAM 通道注意力 + BiFPN 浅层融合 |
| 尺度多变 | 同类目标在不同分辨率影像里大小差几十倍 | BiFPN 多尺度双向融合 |
| 背景复杂 | 建筑/云/阴影干扰 | 归一化降噪（BN）+ 注意力 |
| 部署受限 | 无人机/星载设备算力、功耗严格受限 | 全文主线：轻量化 |

## 2. 两个框"叠得多齐"——IoU

**IoU（交并比）** = 两框交集面积 ÷ 并集面积。检测里几乎所有指标都基于它。

手算例子：框 A=(0,0,4,4)，框 B=(1,1,5,5)
- 交集：重叠区 (1,1)~(4,4)，面积 3×3 = 9
- 并集：16 + 16 − 9 = 23
- IoU = 9/23 ≈ **0.391**

约定：IoU ≥ 某阈值才算"检测到了"。阈值取 0.5 时的指标叫 **mAP50**；
取 0.5, 0.55, ..., 0.95 十档分别算再平均，叫 **mAP50-95（论文写作 mAP）**——
后者对框的精准度要求苛刻得多，是更"硬"的指标。

## 3. 检测质量怎么量化——Precision / Recall / AP / mAP

对**某一个类别**，把模型所有预测框按置信度从高到低排序，逐个判断：

- 与某个真实框 IoU ≥ 阈值且类别正确 → **TP（真正例）**
- 否则 → **FP（假正例）**（框错位置、框错类别、重复框同一目标）

```
Precision（查准率）= TP / (TP + FP)     "我报出来的，有多少是对的？"
Recall   （查全率）= TP / (TP + FN)     "真实存在的，我找到了多少？"
```

两者天然此消彼长：置信度门槛调高 → 准但漏检多；调低 → 全但误检多。
**AP（平均精度）= Precision-Recall 曲线下的面积**，一个数同时概括两端。
**mAP = 所有类别 AP 的平均**（m 表示 mean）。

论文里两组核心数字就是这么来的（DIOR 数据集，20 类取平均）：
- YOLOv11s 基线：mAP50 = 88.4%，mAP = 66.2%
- DSNR-YOLO：mAP50 = **89.0%**，mAP = **66.9%**

> 读表直觉：mAP50 接近 90 说明"目标基本都能找到"；mAP 掉到 66 说明
> "框得非常精确"还很难——遥感小目标密集场景，框差几个像素 IoU 就掉档了。

## 4. 非极大值抑制（NMS）

模型对一个目标常会输出一堆重叠框（比如同一个飞机有 5 个框，IoU 0.8+）。
**NMS** 的流程：
1. 按置信度排序，保留最高的那个框；
2. 删掉与它 IoU > 阈值（如 0.5）的其它框；
3. 对剩下的重复 1~2，直到处理完。

最终每个目标只剩一个框。（论文实验环境里 FPS=128 的计时即包含 NMS。）

## 5. YOLO：一次前向看完整张图

YOLO（You Only Look Once, Redmon 2016）的核心思想：把检测当成**一次性的回归问题**——
整张图喂进网络，**一个前向传播**同时输出所有框的位置+类别。相比当时"先提候选区域
再逐一分类"的两阶段方法（R-CNN 家族），它快了一个数量级。

现代 YOLO（v8~v11）的输出方式：
- 把特征图上每个位置（anchor point）当作"潜在目标中心"；
- 每个位置直接回归：到框四条边的距离 + 各类别分数（**anchor-free**，无手工先验框）；
- 框的四条边不是直接回归一个数，而是回归一个**离散分布**（DFL 技巧，让"框边界
  不确定"可被建模），推理时对分布求期望得到精确坐标。

### YOLOv11 的三段式结构（论文的基线）

```
输入 640×640
   │
┌──▼────────── 主干 Backbone ──────────┐
│ Conv/C3k2 逐级下采样，同时通道数翻倍    │
│ 输出三个尺度的特征图：                  │
│   P3: 80×80 (步幅8)  → 看小目标        │
│   P4: 40×40 (步幅16) → 看中目标        │
│   P5: 20×20 (步幅32) → 看大目标        │
│ 末端 SPPF（多尺度池化）+ C2PSA（空间注意力）│
└──┬───────────────────────────────────┘
┌──▼────────── 颈部 Neck ──────────────┐
│ 自顶向下（上采样）+ 自底向上（下采样）    │
│ 把三尺度特征互相融合（v11 用 PAN 结构）  │
└──┬───────────────────────────────────┘
┌──▼────────── 检测头 Head ────────────┐
│ 每个尺度出两支：框回归(4×reg_max) + 分类 │
│ 训练时用 Task-Aligned 分配器配标签       │
└──────────────────────────────────────┘
```

论文对 v11s 做的手术就发生在这三段里：
主干换掉 C3k2（→DSNRblock）和下采样卷积（→GhostConv）；
颈部整体换成 BiFPN；损失函数换成自适应混合损失。

### v11 组件速查表（后面文档会反复出现）

| 组件 | 一句话 |
|---|---|
| Conv | 卷积+BN+SiLU，v11 的"标准砖块" |
| C3k2 | v11 特征提取模块：1×1 分两支，一支串若干小瓶颈层再拼接（参数多）→ 论文用 DSNRblock 替换 |
| SPPF | 串接多个 5×5 最大池化，让主干"看到"多种感受野 |
| C2PSA | 带位置注意力的模块，增强空间建模 |
| Detect | 检测头：3 个尺度各出一组框+类别分数 |

## 6. 训练时怎么"对答案"——标签分配（先有个概念）

预测点有上万个（80×80+40×40+20×20=8400 个 anchor point），真实目标只有几十个。
训练前要决定"哪个预测点负责哪个目标"——**标签分配**。YOLOv8/v11 用
**Task-Aligned Assigner**：按 `分类得分^α × IoU^β` 给每个"预测-目标"对打综合分，
每个目标取得分最高的 topk 个预测点作为正样本。其余为负样本（只算分类损失）。

v8 系列还有一个精妙设定：**分类标签不是 0/1，而是 0~1 的软标签，数值=该位置的 IoU**。
所以"分类标签"本身就携带了定位质量信息 —— 论文 2.5 节的 SLIDE 损失正是利用这一点
（"根据 IoU 置信度分层调整权重"），docs/06 会展开。
