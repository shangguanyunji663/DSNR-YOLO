## 1. 先懂原版：YOLOv8/v11 损失的三大件

一次训练迭代，损失分三部分（训练日志里的三列）：

| 分量 | 管什么 | 公式核心 |
|---|---|---|
| box_loss | 框的位置准不准 | CIoU（交并比+中心距+长宽比） |
| cls_loss | 类别判得对不对 | **BCE（本文论文要改的就是它）** |
| dfl_loss | 框边界的分布化回归 | DFL（分布焦点损失） |

论文只动 cls 部分。原版 cls 用**等权 BCE**：每个样本（预测点×类别）一视同仁。
论文批评得对："对所有样本采用等权惩罚机制，无法针对性聚焦关键样本。"

### 式(8)：二元交叉熵

```
loss_bce = −[ true·log σ(pred) + (1−true)·log(1−σ(pred)) ]
```

- `pred`：网络输出的 logits；σ = sigmoid 概率；
- `true`：标签。**v8 系列的 true 不是 0/1，而是 0~1 的 IoU 软标签**
  （正样本位置的值 = 预测框与目标框的 IoU）。

手算感受一下"等权"的问题：σ(pred)=0.9 但 true=0.3（模型自信却定位差）：
`loss = −[0.3·ln0.9 + 0.7·ln0.1] = 0.032 + 1.612 ≈ 1.64`
而 σ(pred)=0.1, true=0（正确地报了背景）：`loss = −ln(0.9) ≈ 0.105`
背景点数量是前景的成百上千倍——**梯度几乎全被海量简单负样本淹没**。

## 2. 两味药：ATFL 管难易，SLIDE 管质量

### 式(10) ATFL —— 难度自适应（来源：EFLNet, TGRS 2024，参考文献[22]）

```
ATFL_loss = loss_bce × modulating_factor,    modulating_factor = (1 − pt)^γ
pt = p·true + (1−p)(1−true)     （模型对正确答案的置信度）
```

- pt 小（难样本：模型拿不准/分错）→ (1−pt)^γ ≈ 1 → 权重保留；
- pt 大（简单样本）→ 权重 → 0，几乎不产生梯度。

这就是 Focal Loss 的家族思想。γ 越大，对难样本越"偏心"（本复现取 γ=1.5）。

### 式(9) SLIDE —— IoU 质量分层（来源：YOLO-FaceV2, PR 2024，参考文献[23]）

```
SLIDE_loss = loss_bce × modulating_weight
modulating_weight = exp(−μ·(pt − θ)),    θ = 本batch正样本的平均IoU（质量阈值）
```

- pt < θ（定位质量低于平均，低质量正样本）→ 指数为正 → 权重 >1，**放大**；
- pt > θ（高质量正样本）→ 权重 <1，缩小。

直觉：小目标定位本来就难，IoU 只有 0.4 的"勉强正样本"恰恰是最该学好的；
而 IoU 0.9 的目标已经学得很好，少给点梯度。μ 控制分层陡峭度（本复现取 0.5）。

> 两者都乘在同一个 BCE 上但侧重不同：ATFL 按"分类难易"分层（对正负样本都起效），
> SLIDE 按"定位质量"分层（主要作用于正样本）。一纵一横，互补。

## 3. 式(11)：可学习加权混合 + 正则化

```
total_loss = ω₁·ATFL_loss + ω₂·SLIDE_loss + α + β
```

论文文字解释："ω₁ 和 ω₂ 为 2 个损失的精度权重；α 和 β 为 ATFL 和 SLIDE 的
正则化约束，防止损失的权重无限增大"，且"当某个损失组件更有效时自动提升其权重"。

本复现的实现（`mixed_loss.py`）：

```python
self.w_atfl  = nn.Parameter(torch.tensor(1.0))   # ω₁，可学习
self.w_slide = nn.Parameter(torch.tensor(1.0))   # ω₂，可学习
self.reg_alpha = 0.01                             # α = β（共用一个系数）

# 分类损失段：
cls_mixed = (w_atfl * atfl + w_slide * slide).sum() / target_scores_sum
reg       = reg_alpha * (w_atfl**2 + w_slide**2)  # L2 正则（α·ω₁² + β·ω₂²）
loss[1]   = cls_mixed + reg
```

梯度解读（这正是"自动提升权重"的机理）：
`∂loss/∂ω₁ = ATFL均值 + 2α·ω₁`。若 ATFL 当前对降低损失更有效，
它的损失值相对小、梯度信号使得 ω₁ 往"放大有效分量"的方向走；
L2 项保证 ω 不会为无限压低损失而无界增长。

## 4. 在 ultralytics 里的落点（对照原版源码）

v8DetectionLoss 的分类损失段原本只有两行：

```python
bce_loss = self.bce(pred_scores, target_scores.to(dtype))
loss[1]  = bce_loss.sum() / target_scores_sum
```

我们的 `MixedV8DetectionLoss(v8DetectionLoss)` **只重写了这段**：
框回归（CIoU）与 DFL 保持原版 —— 论文只批评了"等权惩罚"，那只存在于分类损失。

三个工程要点（都很关键，也是学习框架的很好案例）：

1. **多继承**：8.4 版的 `v8DetectionLoss` 是普通类；为让 ω₁/ω₂ 成为可进优化器的
   `nn.Parameter`，我们继承 `(nn.Module, v8DetectionLoss)`，把入口写在 `forward`。
2. **注册进模型**：`DSNRDetectionModel.init_criterion()` 里
   `self.add_module("_dsnr_criterion", criterion)` —— 否则 ω₁/ω₂ 不会出现在
   `model.parameters()` 里。
3. **提前创建**：ultralytics 在第一个 batch 才懒创建损失，那时优化器已建好。
   `register.py` 补丁③在 `build_optimizer` 前先建好损失（本项目已实测：
   训练后 ω 从 1.0 变为 0.9969，证明在优化；参见 docs/09 的"验证清单"）。

## 5. 观察训练动态

训练日志列名是 `box_loss, cls_mixed_loss, dfl_loss`。想看 ω 的演化：
每次评估时打印：

```python
crit = model.model._dsnr_criterion
print(crit.w_atfl.item(), crit.w_slide.item())
```

预期现象：训练早期两个 ω 同步变化；后期若某分量更有效，其 ω 相对上升。
若把 `reg_alpha` 调成 0 再训练，ω 更容易漂移变大 —— 可以自己做个对照实验，
这就是论文式(11) 里 α、β 存在意义的实证。

## 6. 复现自由度声明

论文只给了抽象形式，未公开系数。本复现的取值与出处：

| 系数 | 取值 | 出处/理由 |
|---|---|---|
| γ（ATFL 聚焦） | 1.5 | Focal Loss 家族常用值（γ=2 亦常见） |
| μ（SLIDE 陡峭度） | 0.5 | YOLO-FaceV2 量级，温和分层 |
| θ（质量阈值） | batch 正样本平均 IoU（detach） | SLIDE 原文的动态阈值思想 |
| α = β | 0.01 | 轻正则，防止 ω 漂移不主导训练 |

全部集中在 `mixed_loss.py.__init__`，改一个数字即可做消融。
