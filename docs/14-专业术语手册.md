# 阶段 0 · 深度学习通用基础（课时 1~3）

### 1. 人工智能（AI）
**是什么**：让机器完成需要人类智能的任务的总领域。
**通俗理解**：最大的那把伞，下面分出机器学习、计算机视觉、自然语言处理等。
**哪里遇到**：一切的开端；论文引言的背景板。

### 2. 机器学习（ML）
**是什么**：AI 的子领域——不写死规则，而是让计算机**从数据中自动学习规律**。
**通俗理解**：传统编程是"人写规则喂给数据出答案"；机器学习是"喂数据和答案，
让机器自己总结规则"。
**哪里遇到**：理解"训练"一词的前提。

### 3. 深度学习（DL） ⭐
**是什么**：机器学习的子分支，用**多层（深）神经网络**自动从原始数据中
逐层提取特征。
**通俗理解**：传统机器学习需要人手工设计特征（"我量一下车的长宽比"），
深度学习让网络自己一层层学出该看什么——第一层看边缘，中间层看部件，
深层看整体语义。
**哪里遇到**：所有文档。YOLO、注意力、Mamba 全是深度学习模型。

### 4. 计算机视觉（CV）
**是什么**：让计算机"看懂"图像/视频的学科。子任务包括分类、检测、分割、
跟踪等。
**通俗理解**：给机器装眼睛和视觉皮层。目标检测是其中一个子任务。
**哪里遇到**：本文所有论文都属于 CV 领域。

### 5. 模型（model）
**是什么**：一个带可调参数的函数：输入（图像）→ 计算 → 输出（预测）。
**通俗理解**：一台参数可拧的机器。YOLOv11s 就是"一个函数 + 943 万个旋钮"。
**哪里遇到**：一切。

### 6. 参数（parameter） / 权重（weight） / 偏置（bias）
**是什么**：参数是模型里所有可学习的数；权重是乘在输入上的系数，偏置是
加法项（y = w·x + b 里的 w 和 b）。论文里 "Params 7.15M" = 715 万个这样的数。
**通俗理解**：模型的"记忆"全存在参数里。训练 = 不停拧这些旋钮直到输出正确。
**哪里遇到**：损失反传、参数量统计（verify_model.py）。

### 7. 训练（training） ⭐
**是什么**：用数据+损失函数+梯度下降反复调整参数，使模型预测逼近标签的过程。
**通俗理解**：刷题→对答案→改错题本→再刷题，循环几万次。
**哪里遇到**：docs/09 训练指南整篇。

### 8. 推理（inference）
**是什么**：训练完成后，用固定参数的模型对新数据做预测。
**通俗理解**：考试（不再改错题本）。部署时只推理不训练，所以很多训练期的
结构可以合并简化。
**哪里遇到**：FPS 统计的就是推理速度。

### 9. 数据集：训练集 / 验证集 / 测试集 ⭐
**是什么**：训练集用来调参数；验证集用来选模型/调超参/早停；测试集只在
最后评一次当"高考"。
**通俗理解**：平时作业、模拟考、高考。混用任何两份都会高估真实水平。
**哪里遇到**：论文 3.1.2 的 8:1:1 划分；convert_dior_to_yolo.py 的 split。

### 10. 标签（label）/ 标注（annotation）
**是什么**：数据的"标准答案"。检测任务的标签 = 每个目标的类别 + 框坐标。
**通俗理解**：YOLO 标签 txt 每行"类别 cx cy w h"就是一张图的部分答案。
**哪里遇到**：toy 数据集生成、DIOR 转换脚本。

### 11. 前向传播（forward）
**是什么**：数据从输入层流到输出层的计算过程。
**通俗理解**：答案从第一题写到最后一题。
**哪里遇到**：verify_model.py 的"前向形状检查"。

### 12. 损失函数（loss function） ⭐
**是什么**：量化"预测与标准答案差多少"的函数，训练的目标就是让它变小。
**通俗理解**：错题本扣分总和。损失=惩罚细则：怎么扣分决定模型往哪个方向学
（论文第 2.5 节改进的就是"扣分细则"）。
**哪里遇到**：docs/06 整篇。

### 13. 梯度（gradient） / 反向传播（backpropagation） ⭐
**是什么**：梯度=损失对每个参数的"变化率"（往哪边拧旋钮、损失降多少）；
反向传播=从输出层往输入层逐层算出所有参数梯度的算法。
**通俗理解**：下山时脚下坡度最陡的方向。反向传播=从错题结果倒推每一题的错因。
**哪里遇到**：verify_model.py 里"ω1/ω2 收到梯度"就是在验证这一机制。

### 14. 梯度下降（gradient descent） / 学习率（learning rate, lr） ⭐
**是什么**：参数更新规则：`参数 ← 参数 − lr × 梯度`。lr 是每步走多大。
**通俗理解**：下山步幅。太大→跨过山谷来回震荡（loss 爆炸）；太小→走不动
（loss 不降）。论文取 0.01。
**哪里遇到**：train.py 的 lr0=0.01；排查表里 loss=NaN 常因 lr 太大。

### 15. 优化器（optimizer）：SGD / momentum / Adam
**是什么**：决定"怎么用梯度更新参数"的算法。SGD=朴素下山；momentum=带惯性
（积累历史方向，冲过小坑洼）；Adam=自适应步幅。论文用 SGD+momentum 0.9。
**通俗理解**：普通下山 vs 穿轮滑鞋下山（有惯性）。
**哪里遇到**：train.py 的 optimizer="SGD", momentum=0.9。

### 16. epoch / batch / iteration ⭐
**是什么**：epoch=完整过一遍训练集；batch=一次前向/反向用的样本数；
iteration=处理一个 batch 的一次参数更新。200 epoch = 把训练集完整看 200 遍。
**通俗理解**：刷完一轮题库=1 epoch；一次做 8 题=批大小 8。
**哪里遇到**：论文训练配置（200 epoch / batch 8）；nbs 问题（docs/09 坑3）。

### 17. 过拟合（overfitting） / 欠拟合（underfitting）
**是什么**：过拟合=训练集很好、测试集差（背题）；欠拟合=两边都差（没学会）。
**通俗理解**：背题背到连图片编号都记住，换张新图就不会了。
**哪里遇到**：论文划分数据集"防止过拟合"；PEFT 的低秩约束反而抗过拟合（docs/11）。

### 18. 正则化（regularization）
**是什么**：给训练加约束防止过拟合的手法统称（权重衰减、Dropout、低秩约束…）。
**通俗理解**：给模型戴"紧箍咒"，不让它把训练集背得太死。
**哪里遇到**：weight_decay=0.0005；混合损失的 α、β 项（式 11）。

### 19. 权重衰减（weight decay）
**是什么**：每次更新时把参数往 0 方向轻微收缩（惩罚过大的参数值）。
**通俗理解**：定期把旋钮往中间拧一点，防止某个旋钮拧到夸张位置。
**哪里遇到**：train.py weight_decay=0.0005。

### 20. 超参数（hyperparameter）
**是什么**：训练前由人定的配置（lr、batch、epoch、γ、μ……），与训练中自动
学的"参数"相对。
**通俗理解**：参数是学生自己学的，超参数是老师定的教学计划。
**哪里遇到**：mixed_loss.py 的 gamma/mu/reg_alpha 全是超参数。

### 21. 显存（VRAM） / GPU / CPU
**是什么**：GPU=大规模并行计算芯片，显存=它的专用内存。深度学习的矩阵运算
极度适合 GPU 并行。
**通俗理解**：CPU 是几个教授解题，GPU 是几千个小学生同时算加减法。
**哪里遇到**：RTX 4060 8GB——batch 和 imgsz 调多大受 8GB 显存约束（docs/09 OOM）。

### 22. NaN（Not a Number）
**是什么**：数值运算溢出/非法的产物（0/0、inf−inf）。训练里 loss=NaN 意味着
数值爆炸。
**通俗理解**：计算器显示 Error。常见起因：学习率过大。
**哪里遇到**：docs/09 排查表。

### 23. 张量（tensor） ⭐
**是什么**：多维数组的统称（0维=标量，1维=向量，2维=矩阵，3维+统称张量）。
PyTorch 的基本数据单位。
**通俗理解**：Excel 表格的高维推广——一张图就是一个三层摞起来的数字表格。
**哪里遇到**：一切代码。torch.zeros(1,3,640,640) 就是造一个 4 维张量。

### 24. 形状（shape）与 (B, C, H, W) 约定 ⭐
**是什么**：张量各维度的大小。深度学习图像约定按 批大小B、通道数C、高H、宽W
排列。
**通俗理解**：8 张 640×640 彩图 = (8, 3, 640, 640) 的"数字魔方"。
**哪里遇到**：verify_model.py 的三尺度输出检查全靠读形状。

### 25. 像素（pixel） / 分辨率（resolution）
**是什么**：像素=图像最小单元；分辨率=像素规格（如 1024×768）。
**通俗理解**：分辨率越高马赛克越小。遥感里分辨率还指"地面采样距离"——
0.5m 分辨率=1 像素代表地面 0.5 米，同一架飞机比 30m 影像上大 60 倍。
**哪里遇到**：SIMD 1024×768；论文相对面积比分尺度的动机。

### 26. 通道（channel）
**是什么**：特征图/图像的第 2 维。RGB 图 3 通道；网络内部通道数=特征种类数
（128 通道=128 张"特征图层"叠在一起）。
**通俗理解**：RGB 是三种"颜色滤镜"；网络通道是 128 种"语义滤镜"
（某个通道可能专门亮"竖直边缘"）。
**哪里遇到**：通道注意力（NAM）就是给每个通道打重要性分。

### 27. 特征图（feature map） ⭐
**是什么**：卷积层的输出——输入经过滤波后得到的"响应图"。
**通俗理解**：一层特征图就是一张"某模式出现位置的地图"（比如"竖直边缘地图"）。
**哪里遇到**：主干输出的 P3/P4/P5 都是特征图；BiFPN 融合的就是它们。

### 28. 下采样（downsample） / 上采样（upsample）
**是什么**：下采样=缩小特征图（stride=2 卷积/池化，H、W 减半）；
上采样=放大（最近邻/插值）。
**通俗理解**：缩略图 vs 放大图。下采样省算力但丢小目标细节（高频）——
MambaScan 的 STEL 加 P2 分支就是"少下采样一次"。
**哪里遇到**：yaml 里所有 3,2（stride2）与 nn.Upsample。

### 29. 感受野（receptive field） ⭐
**是什么**：特征图上一个像素"看得见"的原始输入区域大小。
**通俗理解**：每个小格子的视野范围。视野小看局部细节，视野大看全局布局。
**哪里遇到**：空洞卷积（MambaScan）= 花小钱买大感受野；小目标需要小感受野+高分辨率。

### 30. 卷积（convolution） ⭐
**是什么**：小窗口（卷积核）在输入上滑动，每个位置做加权求和输出一个数。
**通俗理解**：拿一个 3×3 的"模板"在图上逐格对比，越像模板的位置输出越大——
自动找模式的小雷达。
**哪里遇到**：一切网络的基本积木。

### 31. 卷积核（kernel） / 步幅（stride） / 填充（padding）
**是什么**：核=模板本身（3×3 的小权重矩阵）；步幅=每次滑几格（2=跳着滑，
输出减半）；填充=输入边缘补 0（保持输出尺寸）。
**通俗理解**：核是印章图案，步幅是盖章间距，padding 是给纸留白边。
**哪里遇到**：yaml 里 Conv[64, 3, 2]=输出64通道、核3×3、步幅2。

### 32. 池化（pooling）
**是什么**：窗口内取最大值（max pooling）或平均值的下采样操作，无参数。
**通俗理解**：把一片区域"汇总成一个代表"。
**哪里遇到**：SPPF 里串了三个 5×5 最大池化。

### 33. 激活函数（activation function） ⭐
**是什么**：逐元素的非线性函数（ReLU、Sigmoid、SiLU…）。没有它，多层网络
等价于一层线性变换。
**通俗理解**：给网络加"弯折"能力——直线怎么叠都是直线，有了弯折才能拟合
任意复杂关系。
**哪里遇到**：ConvBNAct 里的 SiLU；DSNRblock 的 use_act 开关。

### 34. ReLU / Sigmoid / SiLU
**是什么**：ReLU(x)=max(0,x)（负数归零）；Sigmoid 把任意数压到 (0,1)
（输出可当概率/门控）；SiLU(x)=x·sigmoid(x)（YOLO 默认，平滑版 ReLU）。
**通俗理解**：ReLU=负数一概不理；Sigmoid=万能打分器（0~1 分）；SiLU=温和版。
**哪里遇到**：Detect 分类输出用 sigmoid；NAM 的式(5)；BiFPNFusion 用 SiLU 收尾。

### 35. 批归一化（BatchNorm, BN） ⭐
**是什么**：对每个通道，把 batch 内的激活拉回均值0方差1，再用可学习的 γ、β
缩放平移回去。式(1)(2)。
**通俗理解**：每过一层就把音量统一调回标准音量，防止"一层比一层响/轻"。
γ 相当于每个通道的音量偏好——NAM 拿它当注意力权重。
**哪里遇到**：DSNRblock、NAM、docs/04。**本文 γ 即 bn.weight，承重墙**。

### 36. Dropout / 数据增强（augmentation）/ mosaic
**是什么**：Dropout=训练时随机丢弃部分激活；数据增强=随机翻转/缩放/裁剪/
色彩抖动扩充数据多样性；mosaic=四图拼一图（YOLO 特色增强）。
**通俗理解**：都是"人为制造变化防背题"的手段。
**哪里遇到**：训练器自动做；关闭 mosaic 的时机（close_mosaic）。

### 37. 混合精度（AMP, 自动混合精度）
**是什么**：训练时部分计算用 FP16（半精度）省显存提速，关键处保持 FP32。
**通俗理解**：草稿纸用铅笔打草稿（省纸），誊写答案用钢笔（保精度）。
**哪里遇到**：训练日志的 scaler；对 ω 这类标量参数无感。

### 38. 检查点（checkpoint） / .pt 文件 / EMA
**是什么**：checkpoint=训练到某刻的完整存档（参数+优化器状态+轮次）；
.pt=PyTorch 存档后缀；EMA=参数的指数滑动平均副本（更平滑，通常用它验证/保存）。
**通俗理解**：游戏存档；EMA=取"最近若干步的平均位置"当最终成绩。
**哪里遇到**：runs/*/weights/best.pt、last.pt；EMA 剥离 criterion 的坑（docs/09）。

### 39. 预训练权重（pretrained weights） / 微调（fine-tuning）
**是什么**：在大数据集（如 COCO）上先训练好的参数；微调=在其基础上继续训练
适配新任务。
**通俗理解**：转学生带着 previous 学校的底子来上课。
**哪里遇到**：train.py --weights；论文主干被替换后预训练大部分用不上（docs/03）。

### 40. 张量广播（broadcasting）
**是什么**：不同形状张量运算时自动扩展的规则（如 (C,) 的权重乘到 (B,C,H,W) 上）。
**通俗理解**：一行乘数自动复制到每一行去乘。
**哪里遇到**：NAM 的 `w.view(1,-1,1,1) * x`。

# 阶段 1 · 目标检测（课时 4~6）

### 41. 目标检测（object detection） ⭐
**是什么**：同时输出图中每个目标的类别与位置的矩形框的任务。
**通俗理解**：分类答"是什么"，检测还要答"在哪"——输出从 1 个标签变成
几百条"框+类别+分数"。
**哪里遇到**：整个项目。

### 42. 边界框（bounding box, bbox） / xyxy / xywh
**是什么**：框的两种坐标表示：xyxy=(左上x,左上y,右下x,右下y)；
xywh=(中心x,中心y,宽,高)，YOLO 标签用归一化 xywh。
**通俗理解**：描述一个矩形的两种坐标系。归一化后与图片实际尺寸无关
（换分辨率不用改标签）。
**哪里遇到**：toy 标签、损失内部互相转换（xywh2xyxy）。

### 43. 置信度（confidence / score）
**是什么**：模型对"这个框里确实有目标"的打分（0~1）。
**通俗理解**：模型的自信程度。NMS 和评估都按它排序取舍。
**哪里遇到**：predict 输出；val 指标计算。

### 44. IoU（交并比） ⭐
**是什么**：两框交集面积÷并集面积，衡量框的重合度（0~1）。
**通俗理解**：两个圈叠在一起，重叠部分占比。检测里一切"对不对"的判定都基于它。
**哪里遇到**：指标（mAP50/95）、损失（CIoU）、标签分配、NMS——无处不在。

### 45. TP / FP / FN
**是什么**：TP=预测对（框对了类对了）；FP=报错了（框错/类错/重复报）；
FN=漏报（真目标没被报出来）。
**通俗理解**：抓对的小偷 / 冤枉的好人 / 漏掉的小偷。
**哪里遇到**：P、R、AP 的分子分母。

### 46. Precision（查准率） / Recall（查全率） ⭐
**是什么**：P=TP/(TP+FP)"报出来的有多少是对的"；R=TP/(TP+FN)"真实的有多少
被找到了"。二者此消彼长，由置信度阈值调节。
**通俗理解**：宁错杀不放过（P 低 R 高）vs 宁漏过不冤枉（P 高 R 低）。
**哪里遇到**：val.py 输出的四个数。

### 47. AP / mAP / mAP50 / mAP50-95 ⭐
**是什么**：AP=单类别 P-R 曲线下面积；mAP=全类别平均；mAP50=IoU 阈值取 0.5；
mAP50-95=阈值 0.5~0.95 十档取平均（论文记作 mAP）。
**通俗理解**：找得到吗（mAP50）+ 框得准吗（mAP50-95）。后者苛刻得多。
**哪里遇到**：论文表 2~6 的每一格；val.py 输出。

### 48. 置信度阈值 / IoU 阈值
**是什么**：两个不同的门槛——置信度阈值决定"报不报"，IoU 阈值决定"算不算对"。
**通俗理解**：前者是发言门槛，后者是判卷标准。
**哪里遇到**：val.py 默认 conf=0.001（评估尽量全报）；NMS 的 IoU 阈值 0.5~0.7。

### 49. NMS（非极大值抑制） ⭐
**是什么**：按置信度排序，保留最高框、删除与其 IoU 超阈值的其余框，重复直到
处理完——一个目标只留一个框。
**通俗理解**：一群人抢答同一道题，只留声音最大（分最高）的，跟它重复意见的全掐掉。
**哪里遇到**：预测后处理；"重复框同一目标"就是靠它清理。

### 50. anchor（锚框） / anchor-free
**是什么**：anchor-based=预先摆一堆参考框，网络预测相对偏移；
anchor-free=直接从特征图位置回归框（v8/v11 方式）。
**通俗理解**：先撒渔网再修正网位 vs 直接指哪打哪。
**哪里遇到**：v11 是 anchor-free；每个特征图位置=一个候选点。

### 51. 单阶段（one-stage） / 两阶段（two-stage）
**是什么**：两阶段=先提候选区域再分类（R-CNN 家族，准而慢）；单阶段=一次前向
直接出所有框（YOLO，快）。
**通俗理解**：先圈范围再细看 vs 一眼看完全卷。
**哪里遇到**：docs/01 第 5 节 YOLO 思想。

### 52. 主干 / 颈部 / 检测头（backbone / neck / head） ⭐
**是什么**：检测网络三段式：主干提特征、颈部融合多尺度、检测头出预测。
**通俗理解**：眼睛（看）→ 大脑联合处理（综合不同层次）→ 嘴（报告）。
**哪里遇到**：论文图 1 的三大块；yaml 的 backbone/head 字段。

### 53. 特征金字塔 / P3、P4、P5 ⭐
**是什么**：主干逐级下采样得到的不同分辨率特征层：P3=1/8（80×80@640）、
P4=1/16、P5=1/32。P2=1/4（MambaScan 新增）。
**通俗理解**：同一场景的"近景/中景/远景"三份速写。小目标细节只在 P3/P2 有。
**哪里遇到**：三尺度检测；STEL 开 P2 的动机。

### 54. 步幅（stride，检测语境）
**是什么**：该层特征图上 1 格对应原图几像素。P3 步幅 8=1 格管 8×8 原图区域。
**通俗理解**：格子的"管辖范围"。步幅越小对小目标越友好。
**哪里遇到**：verify 检查的 80/40/20 来自 640÷8/16/32。

### 55. FPN / PAN
**是什么**：FPN=自顶向下单向融合（深层语义传给浅层）；PAN=再加自底向上
路径（浅层定位信息传回深层）。v11 颈部=PAN 思想。
**通俗理解**：单向传话 vs 双向传话（还差加权——BiFPN 的事）。
**哪里遇到**：docs/02 第 6 节演进图。

### 56. SPPF（空间金字塔快速池化）
**是什么**：串接多个 5×5 最大池化（等效大核多尺度池化），让深层特征带
多种感受野。
**通俗理解**：用不同大小的取景框各看一遍再汇总。
**哪里遇到**：yaml 第 9 层。

### 57. C2PSA / C3k2
**是什么**：v11 的两个特征模块。C3k2=瓶颈堆叠式特征提取（论文换成 DSNRblock）；
C2PSA=带位置空间注意力的模块（论文保留在主干末端）。
**通俗理解**：C3k2=标准"思考车间"（贵）；C2PSA=带"聚焦"功能的思考车间。
**哪里遇到**：yaml 第 10、16/19/22/25 层。

### 58. DFL（分布焦点损失）
**是什么**：把框的每条边回归成"离散分布"而非单点，推理时取期望——
能表达"边界不确定"。
**通俗理解**：不直接猜"边在哪"，而是猜"边在 7 格的概率 0.6、8 格 0.4"。
**哪里遇到**：训练日志 dfl_loss；Detect 头的 4×reg_max 通道。

### 59. 标签分配（label assignment） / 正负样本 ⭐
**是什么**：决定"哪个预测点负责哪个真实目标"（正样本，算全部损失）；
其余为负样本（只算分类）。v8/v11 用 Task-Aligned（分类分×IoU 综合 topk）。
**通俗理解**：8400 个候选只该有几十个"认领"目标——分配规则就是认领制度。
**哪里遇到**：mixed_loss.py 里 assigner 那几行。

### 60. 软标签（soft label） ⭐
**是什么**：v8 系列把分类标签从 0/1 改成 0~1：正样本位置的标签值=该处预测框
与目标的 IoU。
**通俗理解**：答案不是"对/错"而是"对了七成"。这为 SLIDE"按质量分层"埋下伏笔
——标签本身就带着定位质量信息。
**哪里遇到**：docs/06 式(8) 详解。

# 阶段 2 · 轻量化核心技术（课时 7~9）

### 61. 参数量（Params）
**是什么**：模型可训练参数总数（百万记 M）。决定模型文件大小与显存占用。
**通俗理解**：模型"脑子里旋钮"的总数。yolo11s=9.43M，DSNR-YOLO 目标 7.15M。
**哪里遇到**：表 2~6 每张表；verify_model 输出。

### 62. GFLOPs / MACs ⭐
**是什么**：FLOPs=浮点运算次数（1 次乘加≈2 FLOPs）；G=十亿。衡量一次前向的
计算量，与输入尺寸成正比（论文按 640×640 口径）。
**通俗理解**：跑一遍模型的"电费账单"。21.5G→18.3G=省 15% 电。
**哪里遇到**：表 2 全部行；verify_model 的 GFLOPs 行。

### 63. FPS（每秒帧数）
**是什么**：每秒能处理的图像数，部署端真实吞吐（含前后处理与 NMS）。
**通俗理解**：每秒看几张图。≥25~30 即人眼实时。论文 128 FPS。
**哪里遇到**：表 2~6；受硬件影响极大（只与同硬件比）。

### 64. 1×1 卷积（逐点卷积） ⭐
**是什么**：核为 1×1 的卷积——不对空间做任何事，只做跨通道的线性组合
（可改通道数）。
**通俗理解**：把 128 张"滤镜图"按不同配方混成 64 张——通道搅拌机。
**哪里遇到**：DSNRblock 的逐点卷积；BiFPN 侧向对齐；几乎每个轻量模块都有它。

### 65. 分组卷积（group convolution）
**是什么**：把输入通道分组、各组独立卷积（groups=c 时=深度卷积）。
**通俗理解**：128 个滤镜分成 8 组，各组内部自己开会（省 8 倍交流成本）。
**哪里遇到**：深度可分离卷积的第一步就是 g=c。

### 66. 深度可分离卷积（DepSep / DW+PW） ⭐
**是什么**：深度卷积（每通道独立 K×K，管空间）+ 逐点卷积（1×1，管通道混合）。
参数量约为标准卷积的 1/K²（K=3 时≈1/9）。
**通俗理解**：先"每个滤镜单独处理"再"混合滤镜"——拆开两步省 8~9 倍钱。
**哪里遇到**：DSNRblock 主支路；TriPathHFConv 路径 1/2；GhostConv 内部。**承重墙**。

### 67. GhostConv（幽灵卷积） / 幽灵特征 ⭐
**是什么**：正常卷积只出一半通道（本征特征），另一半用深度可分离 5×5
"廉价操作"生成（幽灵特征），拼接成完整输出。约 2 倍压缩。
**通俗理解**：认真画一半，另一半描红（便宜且相似度高）——因为卷积输出天然
存在大量冗余通道。
**哪里遇到**：yaml 主干 3/5/7 与颈部 20/23。

### 68. 轻量骨干家族（MobileNet / ShuffleNet / PP-LCNet / GhostNet）
**是什么**：以手机端部署为目标的经典轻量网络系列，设计思想（深度可分离、
通道混洗、廉价操作）被"改进 YOLO"论文大量借用为即插即用模块。
**通俗理解**：轻量化界的"老字号配方库"。
**哪里遇到**：论文表 4/6 的对比对手。

### 69. 剪枝（pruning） / 量化（quantization） / 知识蒸馏（distillation）
**是什么**：训练后轻量化三件套：剪枝=砍掉不重要的通道/层；量化=FP32→INT8
低精度存储计算；蒸馏=大模型（教师）教小模型（学生）。
**通俗理解**：减肥（裁掉赘肉）/ 脱水（压缩存储）/ 名师补课（ transfer 本事）。
**哪里遇到**：docs/02 第 7 节"三条正路"——论文选的是结构设计路线。

### 70. 通道注意力（channel attention） ⭐
**是什么**：给每个通道学一个 0~1 的重要性权重，加权后输出。回答"**什么**
特征重要"。
**通俗理解**：128 个滤镜各配一个音量旋钮。
**哪里遇到**：NAM、SE/ECA/CBAM、SCSA。

### 71. 空间注意力（spatial attention）
**是什么**：给特征图每个**位置**学权重。回答"**哪里**重要"。
**通俗理解**：在图上画热点地图。
**哪里遇到**：C2PSA、SCSA、坐标注意力（知道大致行列）。

### 72. SE / ECA / CBAM / SimAM（注意力家族）
**是什么**：SE=全局池化+两层FC；ECA=一维卷积避免降维；CBAM=通道+空间串联；
SimAM=神经元能量函数零参数推导。
**通俗理解**：同一件事（打重要性分）的四种账本记法，繁简不同。
**哪里遇到**：docs/02 第 5 节对比表。

### 73. NAM（归一化注意力模块） ⭐
**是什么**：直接用 BatchNorm 的 γ（bn.weight）当通道注意力权重：
归一化 |γ|→加权→Sigmoid 门控。零新增参数。式(3)(4)(5)。
**通俗理解**：卷积后那个 BN 的 γ 本来就在学"哪个通道该响"，NAM 说"那就直接
拿你的旋钮用，不用新买"。
**哪里遇到**：dsnr_yolo/modules/nam.py；DSNRblock 内部。**承重墙**。

### 74. 残差连接（residual / shortcut） ⭐
**是什么**：把输入直接加到输出：`y = F(x) + x`；形状不匹配时用 1×1 卷积调整
（式 6/7）。
**通俗理解**：开卷考试带小抄——新答案是在原答案基础上"打补丁"，学不动时
至少保持原样，深层网络不再"越训越差"。
**哪里遇到**：DSNRblock 的 shortcut；ResNet 起源。

### 75. 门控（gate/gating）
**是什么**：用 0~1 的系数（常由 sigmoid 生成，可学习）控制两条路径的混合比例。
**通俗理解**：水龙头的混水阀——冷水（直通）热水（NAM）各开多少可学。
**哪里遇到**：DSNRblock 的 nam_gate。

# 阶段 3 · 论文与方法（课时 10~12）

### 76. 基线（baseline）
**是什么**：作为对比起点的标准配置（本文=YOLOv11s）。
**通俗理解**：没有我改进之前的"素颜成绩"。所有提升都相对它计算。
**哪里遇到**：表 2 第一行。

### 77. 消融实验（ablation study） ⭐
**是什么**：逐个添加/移除模块，量化每个组件贡献的实验方法。
**通俗理解**：拆零件验货——一次只拆一个，看成绩掉多少。
**哪里遇到**：论文表 2；MambaScan 缺失的部分（批判点）；docs/07 第 4 节。

### 78. SOTA（state of the art）
**是什么**：当前最高水平。
**通俗理解**：现役冠军。
**哪里遇到**：论文对比实验的语境。

### 79. SPPF / C2PSA 在论文中的角色
（见 56/57——主干末端保留的两个 v11 原装模块，论文没有动它们。）

### 80. DSNRblock ⭐
**是什么**：论文核心模块=深度可分离卷积 + NAM 门控 + 残差的双支路结构，
替换主干 C3k2。名字=Depthwise separable + Normalization attention + Residual。
**通俗理解**：把贵车间换成"便宜车间+免费质检（NAM）+保底传送带（残差）"。
**哪里遇到**：docs/04 整篇；dsnr_block.py。**承重墙**。

### 81. BiFPN（双向特征金字塔） ⭐
**是什么**：EfficientDet 提出的颈部结构：双向路径 + 每路可学习权重的
"快速归一化融合"（wᵢ'=ReLU(wᵢ)/(ΣReLU(w)+ε)）+ 同尺度多路复用。
**通俗理解**：FPN/PAN 是"各路信息等权混音"，BiFPN 给每路装了音量推子
（且推子位置是学出来的）。
**哪里遇到**：docs/05；bifpn.py；yaml head。

### 82. 快速归一化融合（fast normalized fusion）
**是什么**：BiFPN 的加权方式：ReLU 保非负 + 除以总和保归一 + 不用指数（比
softmax 快且稳）。
**通俗理解**：简化版 softmax——效果接近，运算便宜。
**哪里遇到**：bifpn.py forward。

### 83. BCE（二元交叉熵） ⭐
**是什么**：二分类损失：−[y·log p + (1−y)·log(1−p)]。v8 检测的分类损失基础。
**通俗理解**：说真话奖励、说错话重罚的对数罚则。等权 BCE=所有题扣分一样。
**哪里遇到**：式(8)；mixed_loss.py 的 self.bce。

### 84. Focal Loss / 难易样本 / 调制因子
**是什么**：focal=BCE×(1−pt)^γ，压低简单样本权重、聚焦难样本。难易由 pt
（对正确答案的置信度）度量。
**通俗理解**：会做的题少花时间，错题难题多花时间。
**哪里遇到**：式(10) ATFL 的思想来源。

### 85. ATFL（自适应任务焦点损失） / SLIDE（质量分层损失） ⭐
**是什么**：ATFL=按**分类难易**调制（(1−pt)^γ）；SLIDE=按**定位质量**调制
（exp(−μ(pt−θ))，θ=batch 正样本平均 IoU）——前者管"学没学会"，
后者管"框得糙不糙"。
**通俗理解**：一个盯"听不懂课的学生"，一个盯"作业做得毛糙的学生"。
**哪里遇到**：式(9)(10)；mixed_loss.py 核心段。**承重墙**。

### 86. 可学习权重 ω / 正则化约束 α、β
**是什么**：总分类损失=ω₁·ATFL+ω₂·SLIDE；ω 是 nn.Parameter（真参数、进
优化器）；α、β=ω 的 L2 惩罚防其无界增长。式(11)。
**通俗理解**：两个科目的时间分配表（自动调整），α、β 防止偏科到极端。
**哪里遇到**：docs/06 第 3~4 节；register.py 补丁③存在的原因。

# 阶段 4 · 实战（课时 13~15）

### 87. ultralytics
**是什么**：YOLOv8/v11 的官方框架（pip 包）。本项目所有训练/评估/搭建在其上完成。
**通俗理解**：车辆的底盘和仪表盘；我们造的模块是加装零件。
**哪里遇到**：一切脚本；ML2 环境里的 8.4.164 版。

### 88. yaml / 配置文件
**是什么**：人类可读的结构描述文件。ultralytics 读 yaml"搭积木"建网。
**通俗理解**：建筑的施工图纸——每行 [from, repeats, module, args] 指定一块砖。
**哪里遇到**：dsnr_yolo.yaml（整个网络）。

### 89. parse_model（网络解析器）
**是什么**：把 yaml 逐行变成模块实例、并推算每层通道数的函数。
**通俗理解**：看图纸施工的工程师——原版工程师不认识我们的新砖（DSNRblock），
所以要换成认识它的（custom_parse.py）。
**哪里遇到**：register.py 补丁①。

### 90. monkey-patch（猴子补丁）
**是什么**：运行时替换模块/类的方法/属性，不改源码文件。
**通俗理解**：给别人的车临时换一个零件（只在本次驾驶生效，车库里的原件没动）。
**哪里遇到**：register.py 的全部三个补丁。

### 91. 实例换类（model.__class__ = ...）
**是什么**：Python 允许直接改变一个对象的类型标签。用于把建好的模型换成
"带混合损失"的子类，不影响官方模型。
**通俗理解**：不换车，只换行驶证——行驶证写了新规则（init_criterion）就生效了。
**哪里遇到**：register.py 补丁②、swap_class。

### 92. 数据增强（augmentation） / mosaic / close_mosaic
（见 36。补充：ultralytics 默认训练前期开 mosaic、最后 10 轮自动关闭让模型
适应"正常"图像分布。）

### 93. warmup（预热） / 学习率调度（lr scheduler）
**是什么**：warmup=训练初期 lr 从 0 线性升到设定值（防开局爆炸）；
调度=之后按计划衰减（如 cosine）。
**通俗理解**：开车先缓踩油门，再按路况松油门。
**哪里遇到**：train.py 默认开启；玩具实验里前 3 轮 lr 很小的原因。

### 94. 梯度累积 / nbs（名义批大小） ⭐
**是什么**：显存不够跑大 batch 时，积累多个小 batch 的梯度再更新一次——
nbs=等效的大 batch。⚠️ 若每轮 batch 数 < 累积步数，一次更新都不会发生。
**通俗理解**：攒够 64 道题的错题再一起订正——如果一轮只有 10 道题，永远攒不够。
**哪里遇到**：docs/09 坑3（冒烟训练必须 --nbs=batch 的原因）。**承重墙**。

### 95. seed（随机种子）
**是什么**：固定所有随机过程（初始化、打乱、增强）的种子，保证结果可复现。
**通俗理解**：骰子固定摇出同一串点数。
**哪里遇到**：train.py seed=0；转换脚本 --seed。

### 96. VOC 格式 / YOLO 格式
**是什么**：两种标注格式：VOC=每图一个 XML（绝对坐标 xyxy）；
YOLO=每图一个 txt（归一化 xywh，一行一框）。
**通俗理解**：同一套答案的两种笔记法；convert 脚本就是翻译官。
**哪里遇到**：DIOR/SIMD 原始标注是 VOC，需转换。

### 97. 训练曲线 / 收敛（convergence） / 早停（early stopping）
**是什么**：训练曲线=损失/指标随轮次的变化图；收敛=曲线趋于平稳；早停=
验证指标连续多轮不升就停（防过拟合）。
**通俗理解**：看成绩单决定还要不要补课。
**哪里遇到**：runs/ 下的 results.png；patience 参数。

# 阶段 5 · 拓展（课时 16~17）

### 98. 基础模型（foundation model）
**是什么**：海量数据上预训练、可适配多种下游任务的大模型（CLIP/DINOv2/
RingMo/CROMA）。
**通俗理解**：名牌大学毕业的全科生，来你单位只需岗前培训（微调）。
**哪里遇到**：DROS 全篇。

### 99. PEFT（参数高效微调） ⭐
**是什么**：冻结大模型主干、只训练少量新增参数的微调范式（Adapter/
Prefix/LoRA…）。
**通俗理解**：不重修大学，只参加岗前培训——省时省钱，档案（原权重）不动。
**哪里遇到**：docs/11 全篇。**承重墙**。

### 100. LoRA ⭐
**是什么**：PEFT 代表方法：权重更新 ΔW 用低秩乘积 BA 近似（W 冻结，只训
A: d×r 与 B: r×d，r≪d），训完可合并：W'=W+BA。
**通俗理解**：给大机器贴一张"小补丁"——补丁参数极省，撕不撕都行（合并=焊死）。
**哪里遇到**：docs/11 台阶 3。

### 101. 低秩 / 秩（rank）
**是什么**：矩阵的秩=其行/列向量张成空间的维数。低秩=有效信息集中在
少数方向。ΔW≈BA 隐含"更新只活在 r 维子空间"的假设。
**通俗理解**：一张大表格里真正的变化模式其实只有 r 种。
**哪里遇到**：LoRA 的 r；DROS 的子空间选择。

### 102. 子空间（subspace） / 子空间失配 ⭐
**是什么**：大空间里的低维"平面"。失配=LoRA 随机初始化的子空间与下游数据
活跃方向不对齐——容量用错地方。
**通俗理解**：给你一支笔在墙上作画（d 维），却只允许在一条事先随机贴的
窄胶带上画（r 维）——胶带贴的位置错了，功夫全白费。
**哪里遇到**：docs/11 第 3.1 节，DROS 的立论。

### 103. SVD（奇异值分解） / 奇异值
**是什么**：任何矩阵 M=UΣVᵗ，Σ 对角线（奇异值）按重要性排序，U/V 列=重要
方向。取前 r 个方向=最优低秩近似。
**通俗理解**：把一段复杂动作拆解成"由哪几个主方向构成、各占几分力"。
**哪里遇到**：DROS 组件①的初始化。

### 104. 协方差（covariance）
**是什么**：衡量多个变量联动程度的统计量；激活协方差的大特征值方向=
数据真正活跃的特征方向。
**通俗理解**：学生答题的"重心方向"统计——哪几科答得多、答得好。
**哪里遇到**：DROS 的 W·C 初始化。

### 105. 正交（orthogonal） / 松弛正交
**是什么**：正交=互相垂直；正交变换只旋转不缩放（保几何结构）。松弛正交=
允许小幅伸缩的近似正交，在"保结构"与"可适配"间折中。
**通俗理解**：转动一幅画不会拉伸它（正交）；允许轻轻拉一拉角（松弛）
以适应新画框。
**哪里遇到**：DROS 组件②。

### 106. 多模态（multimodal）
**是什么**：多种数据类型（光学图像/SAR/文本…）联合建模。SAR=合成孔径雷达，
相干成像带斑点噪声，与光学差异大。
**通俗理解**：既能看彩色照片又能看雷达图。
**哪里遇到**：MM-DROS 的模态专属基+共享算子。

### 107. 频率 / 高频 / 低频 / 低通滤波 ⭐
**是什么**：图像可分解为不同"变化速度"的成分：低频=大块平滑变化（天空/路面）；
高频=剧烈变化（边缘/角点/纹理）。卷积与下采样天然衰减高频（低通滤波）。
**通俗理解**：马赛克打掉的就是高频——而高频恰恰是小目标的全部线索。
**哪里遇到**：docs/12 台阶 1；TriPathHFConv 的动机。**承重墙**。

### 108. 空洞卷积（dilated/atrous convolution）
**是什么**：卷积核采样点之间插空隙（dilation=d 时 3×3 实际覆盖 (2d+1)²
范围），感受野扩大而参数不变，但跳过局部细节。
**通俗理解**：九宫格章拉开间距盖——一次盖出更大范围，但点与点之间的细节
没采到。
**哪里遇到**：TriPathHFConv 路径 2。

### 109. 坐标注意力（coordinate attention）
**是什么**：沿 H、W 两个方向分别池化再合成权重——通道注意力叠加"大致在
哪一排/列"的位置感知。
**通俗理解**：不但说"什么重要"，还说"大概在哪条横带/竖带上"。
**哪里遇到**：RFCAConv。

### 110. 状态空间模型（SSM） / Mamba / 选择机制 / 线性复杂度 ⭐
**是什么**：源自控制论的序列建模：状态 h 按动力学 A 演化、被输入 B 驱动、
由 C 读出（h'=Ah+Bu, y=Ch+u）。Mamba（2023）让 B/C 随输入变化（选择机制
——重要多记、无关遗忘），保持 O(N) 线性复杂度，替代 O(N²) 的自注意力。
**通俗理解**：读长文章时边读边做"活笔记"（状态）——线性翻页一遍读完且
知道重点记什么；自注意力则是每读一个新词就回头把全文重扫一遍（平方）。
**哪里遇到**：docs/12 台阶 4；MambaBlock。**承重墙**。

### 111. VisDrone
**是什么**：无人机航拍检测基准：260 万标注框、10 类，小/微小目标占绝大多数，
是无人机小目标检测的标准考场。
**哪里遇到**：MambaScan 的主实验。

### 112. P2 分支（stride 4 检测层）
**是什么**：比 P3 更浅一层的高分辨率检测分支（640 输入时 160×160），
为 10~20px 微小目标保住特征。代价：计算量显著增加。
**通俗理解**：普通考试三张卷子，给"极小目标"单独加一张更细的卷子。
**哪里遇到**：MambaScan 的 STEL。

# 附录 · 最容易被误解的 10 组概念（对号入座自查）

1. **epoch vs iteration**：一轮 vs 一次更新（batch=8、1 万图 → 1 epoch=1250 iteration）。
2. **验证集 vs 测试集**：模拟考可以考很多次用来选模型；高考只能考一次。
3. **参数 vs 超参数**：学的 vs 定的。
4. **mAP50 vs mAP50-95**：找得到 vs 框得准。
5. **置信度阈值 vs IoU 阈值**：发言门槛 vs 判卷标准。
6. **深度卷积 vs 深度可分离卷积**：前者只是后者的一半（只管空间不管通道）。
7. **BN 的 γ vs 注意力权重**：NAM 的洞察=二者本来就是一回事。
8. **通道数 vs 类别数**：C 是特征种类数，nc 是要检测的目标类别数，完全不同。
9. **batch 越大训练越快？**：受显存约束；且小数据集配大 nbs 会"永不更新"（坑3）。
10. **"Efficient/轻量"没有统一定义**：先问轻的是结构、训练还是推理口径
   （对照 MambaScan 58M 也自称 Efficient）。
