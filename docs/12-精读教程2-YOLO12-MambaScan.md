## 2. 前置概念：四个台阶

### 台阶 1：图像里的"频率"是什么（TriPathHFConv 的动机）

把图像想象成波：

```
低频 = 平滑的大块变化：天空、大片路面、缓慢的明暗渐变
高频 = 剧烈的快速变化：边缘、角点、细纹理 —— 恰恰是小目标的全部线索！
```

一个 15×15 像素的小目标，去掉高频就剩一团模糊色块——**检测不出来了**。
而卷积（尤其层层堆叠 + 下采样）天然是**低通滤波器**：每过一层，高频衰减一点。
这就是"小目标越到深层越看不见"的频域解释，也是本文第一个模块的靶子。

### 台阶 2：空洞卷积（dilated convolution）——不花参数的"望远镜"

普通 3×3 卷积的**感受野**（一个输出像素能"看到"的输入范围）是 3×3。
**空洞卷积**在卷积核的点与点之间插空隙：dilation=2 的 3×3 卷积，实际采样的是
一个"隔一个点采一个"的 5×5 范围——**感受野 5×5，参数还是 9 个**。

```
普通 3×3 (d=1)        空洞 3×3 (d=2)
■ ■ ■                 ■   ■   ■
■ ■ ■                 ■   ■   ■        采样的范围大了，参数不变
■ ■ ■                 ■   ■   ■
```

代价：插空隙会"跳过"一些局部细节——所以它适合与普通卷积**并联**互补，
而不是单独替换。这正是本文"三路径"的由来。

### 台阶 3：坐标注意力（coordinate attention）——知道"在哪里"的通道注意力

主线课程学过通道注意力（SE/NAM）：给每个通道一个权重，回答"**什么**重要"。
但它不看位置。**坐标注意力**把特征图沿 H 和 W 两个方向分别池化，生成两个
方向感知的条带，再合成权重——同时回答"什么重要"和"**大概在哪一排/哪一列**"。
对航拍视角（目标散布在图面各处）特别合适。本文的 RFCAConv = 感受野增强 +
坐标注意力，用于**下采样**这一信息流失的关键点。

### 台阶 4：状态空间模型与 Mamba——"线性复杂度的全局视野"

这是本文最"新"的部件，从零讲：

**问题**：要让网络看到全图上下文（"这一小坨像素是不是车，要看它是不是在路上、
周围像不像停车场"），有两种经典做法：
- RNN/LSTM：逐个位置滚动处理，**计算量 O(N) 线性**，但无法并行、记性差；
- Transformer 自注意力：任意两点直接交互，效果最好，但两两配对 **O(N²) 平方**——
  无人机图 960×960 展开的 token 数巨大，平方复杂度吃不消。

**状态空间模型（SSM）**是第三条路，源自控制论。连续形式：

```
h'(t) = A·h(t) + B·u(t)     ← "状态" h 按内部动力学 A 演化，被输入 u 驱动
y(t)  = C·h(t) + D·u(t)     ← 输出是状态的读出
```

把它离散化、按序列逐位置滚动，就是一条**线性复杂度 O(N)** 的"记忆线"：
每个位置的输出都携带之前所有位置的浓缩信息（h）——全局视野，线性代价。

**Mamba（2023）**的贡献是**选择机制（selective scan）**：让 B、C（甚至 A）
随输入内容变化——"重要的信息多记，无关的主动遗忘"，克服了老 SSM
"对一切输入一视同仁"的缺陷，性能逼近注意力，复杂度仍是线性。
2024 年起被大量搬进视觉骨干（Vision Mamba、VMamba……），YOLO12 的
原型结构也内置了类似区域扫描块。⚠️ 本文 MambaBlock 的具体扫描方式
（如何把 2D 特征图摊平成 1D 序列、双向还是四向扫描）日报未详述，
请以原文为准——理解"线性复杂度拿全局上下文"这个定位即可。

```
复杂度对比（N = 位置数，如 960/32=30 → 900 个 token/层）：
  自注意力:  N²  = 810 000 对交互
  Mamba:     N   = 900 步滚动          ← 这就是"高效"的含义
```

## 3. 五个模块精读（按数据流动顺序）

```
输入 960×960
   │
① TriPathHFConv（主干浅层 2~4 层替换）     ← 保住高频细节
   │
② RFCAConv（下采样处替换）                 ← 下采样别丢位置信息
   │
   … 主干中层 …
   │
③ MambaBlock（主干最深层插入）             ← 线性复杂度的全局上下文
   │
④ GSPN SCSA（颈部 → 头部之间）             ← 线性扫描空间注意力，强化流向头部的信息
   │
⑤ STEL 小目标增强层（新增 P2/4 检测分支）   ← 给 15px 目标专门开一路
   ▼
检测输出（P2, P3, P4, [P5]）
```

### 3.1 ① TriPathHFConv——三条路并联，各补一样东西（浅层，主干第 2~4 层）

小目标信息最丰富的浅层，把标准卷积替换为三条并联路径（日报描述）：

```
                 ┌── 路径1：基本深度可分离卷积 ── 标准"性价比"特征（主线课老朋友）
输入特征 ────────┼── 路径2：空洞深度可分离卷积 ── 大感受野上下文（台阶2）
                 └── 路径3：高频增强卷积 ────── 用 sigmoid 做内容自适应注意力，
                                                按"每处内容的高频重要性"加权
        三路输出拼接/融合 → 输出
```

设计逻辑：**浅层是高频信息的最后防线**，值得花结构预算；三条路径覆盖
"局部细节 / 大范围上下文 / 高频显著性"三种互补信息，且全部基于深度可分离
卷积控制参数（与 DSNRblock 用的是同一块"公共底座"）。

### 3.2 ② RFCAConv——给下采样装上"位置记忆"

下采样（stride 2）每发生一次，空间尺寸减半，小目标的证据就稀释一档。
RFCAConv = 感受野增强 + 坐标注意力（台阶 3）：在压缩分辨率之前，
先让网络明确"哪些位置值得保留"。日报给出代价：**+1.5% 参数、+2.3% FLOPs**。

### 3.3 ③ MambaBlock——深层全局上下文的"线性价格"

放在主干最深层（此时分辨率已低、语义已强），补全局上下文（台阶 4）。
角色对应 YOLO12/11 里的注意力块（主线课程里的 C2PSA）——但把"全局建模"
从平方复杂度换成线性。**定位**：无人机图大、目标散布全图，全局上下文收益高，
而平方复杂度的自注意力在 960×960 输入下代价过高——这正是选 Mamba 的理由。

### 3.4 ④ GSPN SCSA——颈部到头部的"线性扫描注意力"

SCSA = 空间与通道协同注意（主线 docs/02 的注意力家族里提过这一方向）。
GSPN 让空间注意力按**线性扫描**方式计算（O(H+W) 量级/通道，日报表述），
进一步压注意力的空间成本。作用位置在颈部输出→检测头之间：**最后一道
"信息聚焦"关卡**——确保花功夫融合好的特征，按空间重要性加权后送进检测头。

### 3.5 ⑤ STEL 小目标增强层——专门为 15px 目标开的"第四条检测尺度"

这是本文**最重**的一笔。回忆主线课程：检测尺度越浅（步幅越小），小目标特征越
完整。VisDrone 里大量目标只有 10~20 像素：

```
一个 16×16 的目标经过各步幅后的特征图大小：
  P3 (stride 8)  → 2×2 像素   ← 只剩 4 个格子，信息濒临耗尽
  P2 (stride 4)  → 4×4 像素   ← 16 个格子，还有得看 ★STEL 新增这路
```

STEL：在颈部新增 P2/4 高分辨率分支并接进检测头（通道压到 128 控制开销）。
代价与收益（日报数字）：**+18.7% 计算量，换小目标 AP +23.4%**——
对以微小目标为主的数据集，这笔交易非常划算。

## 4. 实验解读与批判性阅读

### 4.1 成绩怎么看

VisDrone @960×960：mAP50 **60.0**，mAP50-95 **38.6**（L 版 58M/115G）。
两个背景数字帮你建立坐标系：多数 YOLOv8/11 系检测器在 VisDrone@640 的
mAP50 大约在 40% 上下——60% 是相当高的水平；但注意两个前提：
① 960 大分辨率输入本身就显著提升小目标 AP（占大便宜）；② L 版体量不小。

### 4.2 批判性阅读清单（日报分析也点了这些，务必内化）

1. **没有消融表**：五个模块各自贡献多少？没有数据。复现它的第一件事就是补
   "逐个去掉模块"的实验（对照主线课程 docs/07 表2 的标准）；
2. **对比口径不一致**：把自己的 960×960 结果与他人的 640×640 结果放同一张表——
   分辨率不同不可直接比。它自己也报了 640 下 51.6 mAP50，领先幅度小得多；
3. **"小目标 AP +23.4%" 缺表格出处**：漂亮数字先找实验设置（是 AP_small 还是
   全类均值？和谁比？）；
4. **体量定位要诚实**：58M/115G（L 版）远超"边缘部署"档位——它的"Efficient"
   指的是"相对大分辨率高精度模型的效率"，不是 DSNR-YOLO 那种边缘级轻量。

> 这份清单不是贬低论文——它是"从摘要级信息读论文"的标准动作，
> 也是你以后写论文要提前自查的清单。

## 5. 与 DSNR-YOLO 的全面对照（本教程的灵魂表格）

| 维度 | DSNR-YOLO（主线） | YOLO12-MambaScan |
|---|---|---|
| 目标场景 | 卫星遥感（DIOR/SIMD） | 无人机航拍（VisDrone） |
| 核心矛盾 | 边缘部署（算力/功耗受限） | 小目标信息太弱（精度优先） |
| 特征提取积木 | 深度可分离卷积 + NAM + 残差（DSNRblock） | 深度可分离 + 空洞 + **高频增强**三路并联 |
| 下采样 | GhostConv | RFCAConv（坐标注意力） |
| 全局建模 | C2PSA 注意力（原版保留） | **Mamba** 状态空间（线性复杂度） |
| 颈部 | BiFPN 双向加权融合 | 颈部+头部间线性扫描注意力 |
| 小目标手段 | 浅层 P3 + 轻量化保精度 | **新增 P2 分支（STEL）** |
| 损失 | ATFL+SLIDE 自适应混合 | ⚠️ 日报未提及改动 |
| 体量 | ~7M / ~18 GFLOPs | 27~58M / 75~115 GFLOPs |
| FPS 定位 | 128 FPS（边缘实时） | 未强调（精度优先） |

**规律总结**（写论文时可直接套用的观察）：
所有"小目标 + 高效"的检测器都在回答同一组问题——
**① 高频细节在哪一环丢的，就在哪一环补（浅层卷积/下采样）；② 全局上下文用
什么复杂度买（注意力/状态空间/融合网络）；③ 要不要为小目标单开检测尺度
（P2 分支）；④ 训练信号怎么偏向难样本（损失设计）。**
四问的答案组合起来，就是一篇"改进 YOLO"论文的骨架。

## 6. 自测（答案在括号内）

1. 为什么说卷积是"低通滤波器"？（答：卷积加权平均抹平剧烈变化=衰减高频，
   而高频正是小目标的边缘/纹理线索）
2. dilation=2 的 3×3 空洞卷积：感受野多大？参数多少？（答：5×5；9 个，不变）
3. Mamba 相比自注意力的根本优势是什么？（答：序列处理 O(N) 线性 vs O(N²) 平方，
   同时靠选择机制保住"按内容取舍记忆"的能力）
4. 一个 16×16 的目标在 stride 8 的 P3 上只剩几个格子？STEL 为什么开 stride 4？（答：
   2×2=4 格；P2 有 4×4=16 格，信息更完整）
5. 本文最该补的实验是什么？（答：五模块消融 + 同分辨率口径对比）
