## 1. 标准卷积的参数量与计算量

一个卷积层：输入通道 C_in，输出通道 C_out，核大小 K×K，特征图 H×W。

**参数量**（不含 bias）：

```
Params = C_out × C_in × K × K
```

**计算量（MACs，乘加次数）**：每个输出像素要做 C_in×K×K 次乘加，共 H_out×W_out 个像素：

```
MACs = C_out × C_in × K × K × H_out × W_out
```

手算：3×3 卷积，C_in=64 → C_out=128，输出 40×40：
- Params = 128 × 64 × 3 × 3 = **73 728**
- MACs = 73 728 × 40 × 40 = **118 M**（约 0.118 GFLOPs，1 MAC≈2 FLOPs）

> 论文表2里 "GFLOPs" 就是对每层 MACs×2 求和。基线 YOLOv11s = 21.5 GFLOPs。

## 2. 深度可分离卷积（Depthwise Separable, DepSep）——省 8~9 倍

核心观察：标准卷积把"**空间滤波**"和"**通道混合**"两件事捆绑在一次 K×K 卷积里。
Chollet（Xception, CVPR2017，论文参考文献[27]）指出：可以拆开做，几乎不损精度：

```
标准卷积：          C_in ──[K×K×C_in→C_out]──→ C_out        （一步完成两件事）

深度可分离卷积：
   第①步 深度卷积 DW：每个通道独立卷   C_in ──[K×K, groups=C_in]──→ C_in
   第②步 逐点卷积 PW：1×1 混合通道     C_in ──[1×1]──→ C_out
```

**参数量对比**（同样 64→128, 3×3）：

```
标准卷积：   128 × 64 × 3 × 3             = 73 728
DepSep：     深度卷积 64 × 3 × 3    = 576
             逐点卷积 128 × 64 × 1×1 = 8 192
             合计                    = 8 768    → 压缩 8.4 倍 ✓
```

一般结论：压缩比 ≈ K²（K=3 时约 9 倍，再加 BN 差异略降）。
**计算量同理压缩**——这就是论文主干能从 21.5 GFLOPs 降到 18.9 GFLOPs 的主力。

代价：逐通道独立卷积割裂了通道间交流，特征表达能力略降 → 论文用 NAM 注意力 + 残差
来"补"（这就是 DSNRblock 的设计动机，docs/04 详解）。

## 3. GhostConv：一半卷积 + 一半"廉价操作"

GhostNet（Han et al., CVPR2020，参考文献[20]）观察到：卷积输出的特征图里
**大量通道高度相似**（论文称之为"幽灵/冗余特征"）。既然如此，何必用昂贵卷积把
每个通道都认真算一遍？

GhostConv 的做法：

```
输入 ──[正常卷积, 通道数 C_out/2]──→ 本征特征 (一半)
              │
              └──[深度可分离 5×5 廉价变换]──→ 幽灵特征 (另一半)
输出 = concat(本征, 幽灵)   通道数仍是 C_out
```

手算（64→128，空间 40×40）：

```
标准 3×3 卷积：  128×64×9 = 73 728
GhostConv：      本征 64×64×9 = 36 864
                 幽灵 64×5×5 (深度可分离) = 1 600
                 合计 = 38 464           → 约 1.9 倍压缩
```

> 注意 GhostConv 压缩比(≈2×)不如完整 DepSep(≈9×)，因为它只把**一半**通道换成廉价
> 操作，保留了较强的本征特征。论文在**下采样卷积**和**颈部**用它，是"轻量但不激进"
> 的折中（对应表2：模型2，GFLOPs 18.9→16.1）。

## 4. 归一化（BatchNorm）——式(1)(2) 的直觉

论文式(1)(2)：

```
x̂ᵢ = (xᵢ − μ_B) / √(σ_B² + ε)        ← 把每个通道的分布拉回均值0方差1
yᵢ  = γ·x̂ᵢ + β                        ← 再用可学习的 γ、β 恢复表达能力
```

三层意义：
1. **训练稳定**：前层参数一更新，后续输入分布就"漂移"（internal covariate shift），
   BN 抹平这种漂移，允许更大的学习率；
2. **降噪**：遥感图像光照/背景差异大，均值中心化+方差标准化消除全局强度偏移，
   凸显小目标边缘纹理——论文 2.2 节明确把这一点列为 NAM 的协同机制；
3. **γ 是免费的通道重要性指标**：γ 学得越大 → 网络越依赖该通道。
   NAM 注意力直接把 |γ| 当权重用（下一节）。

> 工程细节：卷积后接 BN 时，卷积不再需要 bias（被 β 覆盖）——所以本项目所有
> Conv 都 `bias=False`，又省一点参数。

## 5. 通道注意力家族：从 SE 到 NAM

注意力机制 = 让网络自己学"哪个通道/位置重要"。通道注意力演化：

| 方法 | 权重怎么来 | 额外参数 | 特点 |
|---|---|---|---|
| SE (2018) | 全局池化→MLP→Sigmoid | 多（两层FC） | 开山之作 |
| ECA (2020) | 全局池化→1D卷积（跨通道交互） | 极少 | 避免"降维失联" |
| SimAM (2021) | 由神经元能量函数直接推导 | **0** | 完全无参 |
| **NAM (2021)** | **直接用 BN 的 γ/μ/σ** | **0** | 本文采用 ✓ |

**NAM（Normalization-based Attention Module，参考文献[13]）**的洞察：
BN 的 γ 本来就在学"每个通道的重要性"——何必再造一套注意力网络？直接把
归一化参数当注意力权重。论文只用了 NAM 的**通道分支**：

```
式(3)  weight_i = |γ_i| / Σ|γ_i|      ← γ 绝对值归一化
式(4)  x_att   = weight ⊙ x           ← 按通道加权
式(5)  x_out   = σ(x_att) ⊙ x         ← Sigmoid 门控再乘一次
```

零新增参数 + 与 BN 的"归一化降噪"协同 —— 非常契合"轻量化 + 小目标"的场景需求。
代码实现：`dsnr_yolo/modules/nam.py`（50 行，含逐行注释）。

## 6. 特征金字塔家族：FPN → PAN → BiFPN

目标检测要同时看大目标和小目标 → 需要把"深层语义强、分辨率低"和
"浅层分辨率高、语义弱"的特征图**融合**。三条技术路线：

```
FPN (2017)：自顶向下单向
   P5 ──上采样──→ 加到 P4 ──上采样──→ 加到 P3
   （深层语义传给浅层，但浅层信息传不回深层）

PAN (2018)：FPN 之后再自底向上加一条下采样路径（YOLOv8/v11 采用）
   两条单向通路，融合时直接 concat/相加，各路等权

BiFPN (EfficientDet, 2020，论文参考文献[21])：
   ① 双向路径同 PAN，但每个融合节点改为【可学习加权】：
        out = Σ (ReLU(w_i) / (ΣReLU(w_j)+ε)) × x_i
      论文图4中的红色箭头就是这些跨层加权连接；
   ② 反复利用同一尺度的多路输入（P4 节点同时吃"侧向、顶向下、底向上"三路）；
   ③ 融合前用 1×1 对齐通道（本文 yaml 里 11/12/13 三层）。
```

为什么 BiFPN 适配遥感（论文 2.4 节）：遥感图像**背景占比极高**，等权融合会把
小目标特征稀释在背景里；可学习权重让网络自动"偏向"含小目标的浅层高分辨率特征。
代码：`dsnr_yolo/modules/bifpn.py` + `dsnr_yolo/models/dsnr_yolo.yaml` 的 head 段。

## 7. 模型轻量化的三条正路（论文所用技术的定位）

| 路线 | 手段 | 论文用了吗 |
|---|---|---|
| 结构设计 | 深度可分离卷积、GhostConv、轻量骨干 | ✓（DSNRblock+GhostConv） |
| 剪枝 | 训练后砍掉不重要的通道/层 | ✗ |
| 量化/蒸馏 | FP16/INT8、大模型教小模型 | ✗ |

结构设计的好处：**一次训练即得**，无需多阶段流水线，且对部署友好——
这是"魔改 YOLO"类论文的主流做法。
